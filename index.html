PT Lernkarten ist umgezogen

Aus urheberrechtlichen Gründen ist die Lernplattform nicht mehr öffentlich im Internet erreichbar. Ihr findet sie ab sofort nur noch unter der neuen Adresse – dort ist sie ausschließlich für Schülerinnen und Schüler mit einer @physiocampus.net-Adresse zugänglich.

Zur Lernplattform: lernen.charyo.shop

Speichert euch die neue Adresse am besten gleich als Lesezeichen.

Beim ersten Mal: Account anlegen

  1. Öffnet lernen.charyo.shop.

  2. Klickt auf der Anmeldeseite auf Registrieren. Dies findet ihr unten im Fenster unter: Noch kein Konto? Registrieren.

  3. Gebt eure Schul-E-Mail-Adresse ein, also die Adresse, die auf @physiocampus.net endet. Schreibt sie komplett in Kleinbuchstaben. Andere Adressen (Gmail, Web.de usw.) werden nicht angenommen.

  4. Ihr bekommt eine E-Mail mit einem 6-stelligen Code an diese Adresse. Tippt den Code auf der Seite ein.

  5. Fertig – euer Account ist angelegt und ihr seid direkt angemeldet.

Danach: Anmelden

Ein Passwort für die Lernplattform gibt es nicht. Bei jeder Anmeldung gebt ihr eure @physiocampus.net-Adresse ein und bekommt einen neuen 6-stelligen Code per E-Mail, den ihr auf der Seite eintippt.

Gut zu wissen: Der Code ist 10 Minuten gültig. Lasst die Seite mit dem Code-Feld geöffnet, während ihr die E-Mail abruft. Nach der Anmeldung bleibt ihr auf dem Gerät einen Tag lang angemeldet.

So kommt ihr an die E-Mail mit dem Code

Der Code wird an euer Schul-Postfach geschickt. Das Postfach läuft über Outlook. Ihr braucht dafür eure @physiocampus.net-Adresse und das dazugehörige Passwort, das ihr von der Schule bekommen habt.

  • Im Browser: Öffnet outlook.office.com und meldet euch mit eurer Schul-Adresse und dem Passwort an.

  • Auf dem Handy: Installiert die App „Microsoft Outlook“ und fügt dort euer Schul-Konto mit Adresse und Passwort hinzu.

Praktisch ist es, die Lernplattform auf einem Gerät geöffnet zu lassen und den Code auf dem Handy in Outlook nachzuschauen.

Wenn etwas nicht klappt

  • Es kommt keine E-Mail an: Wartet ein bis zwei Minuten und schaut auch im Ordner „Junk-E-Mail“ nach. Prüft, ob ihr die Adresse ohne Tippfehler eingegeben habt.

  • Der Code wird nicht angenommen: Er ist vermutlich abgelaufen. Startet die Anmeldung neu und benutzt den Code aus der neuesten E-Mail.

  • Die Adresse wird abgelehnt: Es funktionieren nur Adressen, die auf @physiocampus.net enden.

  • Bei allen anderen Sachen wendet euch an PT4
