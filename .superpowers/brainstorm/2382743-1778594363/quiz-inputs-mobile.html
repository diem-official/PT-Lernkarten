A — Wie bisher (skaliert mit)

Eingabefelder bleiben auf dem Bild, skalieren mit der Bildgröße. Einfachste Lösung, kein Umbau nötig.

Vorteile

  • Kein Code-Umbau
  • Räumlicher Kontext bleibt

Nachteile

  • Felder sehr klein (~9px)
  • Tippen schwierig
  • Tastatur verdeckt Bild

B — Nummern auf Bild + Liste unten

Auf dem Bild nur nummerierte Pins (tippbar). Die Eingabefelder erscheinen als scrollbare Liste unterhalb des Bildes — groß und tippfreundlich.

Vorteile

  • Komfortable Eingabe
  • Bild bleibt groß & sauber

Nachteile

  • Räumlicher Kontext reduziert

C — Tippen auf Pin → Popup

Auf dem Bild nummerierte Pins. Tippen auf einen Pin öffnet ein Eingabe-Popup direkt am unteren Bildrand. Bild bleibt vollständig sichtbar.

Vorteile

  • Bild stets sichtbar
  • Direkter Bezug Pin↔Eingabe

Nachteile

  • Kein Überblick über alle Felder
  • Mehr JS-Aufwand
